# ANS Agent

Self-hosted multi-model agent workspace with Claude Code execution, routing, sessions, workspace tools, Git/diff inspection, Best-of-N and realtime events.

## Quick start

    python -m venv .venv
    pip install -r requirements.txt
    cp .env.example .env
    python run.py

Open http://localhost:8080.

Complete setup guide: docs/USER_GUIDE.md
