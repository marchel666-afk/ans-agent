# Configuration

Required: Claude Code installed and authenticated on the machine running ANS.
Optional providers: OPENAI_API_KEY, GEMINI_API_KEY, OPENROUTER_API_KEY.
GitHub integration: GITHUB_TOKEN and GITHUB_REPO.
Runtime: ANS_WORKSPACE, ANS_DB, ANS_AUTH_TOKEN_FILE.
Never commit .env, data/auth.token, provider keys or GitHub tokens.
